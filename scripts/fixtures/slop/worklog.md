# Worklog — фикстура slop (не настоящий прогон)

Файл существует только для `scripts/lint-slop.test.mjs`: линтеру нужен worklog,
чтобы применить scoping «референс побеждает» и погасить утверждённые исключения.
Структура повторяет `templates/worklog.md` в минимальном объёме.

## Источники композиции

| Страница / секция | Источник (`reference` / `library` / `invented`) | Evidence |
| --- | --- | --- |
| home/hero (+nav) | reference | фикстура: находки должны понижаться до warning |
| home/manifesto | reference | фикстура: то же |
| home/teachers | invented | фикстура: находки в полной строгости |

## Утверждённые исключения

- `T12` — hover-тень на `.cta`: фикстура проверяет, что гашение по этому списку
  работает и правило уходит в группу «Чисто по», а не в находки.
