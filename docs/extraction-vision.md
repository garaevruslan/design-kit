# Extraction: vision-путь (скриншоты и картинки)

Правила фазы 1 для референса-изображения: скриншоты, шоты с Dribbble, Mobbin,
Behance, Pinterest, экспорт из Figma-превью. Результат фиксируется в
`project/reference-study.md` со статусом `vision-only`.

Ключевое правило контракта — `vision-values-snapped`: каждое значение, снятое
с картинки, (а) приводится к консистентной шкале, (б) получает пометку уверенности
`high` / `medium` / `low`, (в) уступает CSS-пути, если живой аналог доступен.

## Шаг 0 — обязательная попытка найти живой оригинал

До любого визуального извлечения:

1. Осмотреть картинку на водяные знаки, логотипы, URL в футере/адресной строке.
2. Поискать по названию продукта/бренда, тексту заголовков с картинки.
3. Выполнить обратный поиск по изображению (Google Lens и аналоги).
4. Проверить страницу-источник шота (описание на Dribbble/Mobbin часто содержит
   ссылку на живой продукт).

Живой оригинал найден → переключиться на `docs/extraction-css.md`, статус
`ran-original` (или `mixed`, если часть референсов остаётся картинками).
Не найден → зафиксировать в reference-study.md, что поиск выполнен и чем закончился,
и продолжать по этому доку. Пропуск шага 0 = нарушение `vision-values-snapped` (в).

## Что запрещено

- Выдавать вымышленные значения за извлечённые: если значение не читается
  с картинки, писать `unknown` + предложение по шкале, а не «правдоподобное» число.
- Присваивать `high` confidence оценкам «на глаз» (любым, кроме пипетки и
  прямых измерений в пикселях на неискажённом скриншоте 1:1).
- Переносить сырые пиксельные замеры в study без снэпа к шкале.
- Утверждать конкретный шрифт без проверки (Identifont, WhatTheFont, сравнение
  начертаний) — иначе `font: unknown, closest match: Inter (confidence: low)`.

## Цвета

- Снимать пипеткой (color picker по пикселям изображения), не «на глаз».
- Каждый цвет — по нескольким точкам (минимум 3) одной и той же поверхности:
  JPEG-артефакты, градиенты и наложения сдвигают отдельные пиксели. В study идёт
  медианное значение; разброс точек > ~5% по каналам → confidence не выше `medium`.
- Группировать по ролям: background / text / accent / border — как в CSS-пути.
- Полупрозрачные слои и тени: снятое значение — композит, не исходный токен;
  помечать `composite` и confidence `low`.
- Confidence: пипетка по плоской заливке → `high`; пипетка по мелкому
  тексту/градиенту → `medium`; оценка без пипетки → `low` и пометка `estimated`.

## Типографика

- Оценивать через **соотношения**, а не абсолютные пиксели: h1/body ratio,
  h2/body ratio, line-height/font-size. Картинка может быть отскейлена — ratio
  инвариантен, пиксели нет.
- Взять высоту строчных букв body-текста за базу, измерить остальные уровни
  относительно неё, затем построить шкалу: назначить body = ближайший стандартный
  размер (16px по умолчанию) и снэпнуть уровни к ближайшим шагам type scale
  (например 1.25 ratio: 16/20/25/31/39/49).
- Weight оценивать по градациям 400/500/600/700 — промежуточные значения
  не выдумывать.
- Абсолютные размеры из vision-пути всегда confidence не выше `medium`.

## Spacing, радиусы, тени

- Измерять отступы в пикселях картинки, затем нормировать через ту же базу,
  что и типографика, и снэпнуть к шкале с базовым шагом 4 или 8
  (не 17px → 16px; не 37px → 36 или 40 по ближайшему шагу, пометить снэп).
- Радиусы читать по кнопкам и карточкам, снэпнуть к малому набору
  (например 4/8/12/16/9999-pill).
- Тени с картинки принципиально неточны (композит с фоном): описывать
  качественно (мягкая/жёсткая, смещение, разлёт) + предложить значение из
  типовых пресетов, confidence `low`.

## Иконки и моушен (vision-путь)

- **Иконки:** стиль иконок на картинке часто неразличим. Зафиксировать что видно
  (контурные / сплошные, примерная толщина штриха), выбрать вес Reicon; при
  неразличимости — `outline` по умолчанию, confidence `low`, вынести на гейт 1
  (`docs/icons.md` §Фаза 1). Сами SVG всё равно берутся из Reicon (`icons-from-collection`),
  а не срисовываются с картинки.
- **Моушен:** с картинок не извлекается (уровни A/B требуют живого сайта). Весь моушен
  проекта на vision-пути — **уровень C**: изобретение по правилу мотивации из
  `library/motion/` на фазе 5 (`docs/motion.md`). Фиксируется в «Ограничениях».

## Формат записи значения

Каждое значение в reference-study.md записывается так:

```
raw: 21px (замер) → snapped: 20px (type scale step 2)
confidence: medium
evidence: hero heading, shot dribbble-hero.png, точки (120,80)(340,80)
```

Поля `raw`, `snapped`, `confidence`, `evidence` обязательны. Значение без
`raw`-происхождения (чистое предложение агента) помечается `proposed`, не
`extracted` — смешивать категории запрещено (`reference-source-of-truth`).

## Ограничения статуса vision-only

В reference-study.md обязательно фиксируются ограничения: что не извлекаемо
с картинок (hover/focus-состояния, брейкпоинты, реальная сетка, тени, анимации),
какие секции видны частично, какое качество исходников. Фаза 2 обязана опираться
на эти ограничения: недостающие группы токенов строятся по шкалам с пометкой
`proposed` и проходят гейт 1 с явным указанием на это человеку.

## Чек-лист выхода

- [ ] Попытка найти живой оригинал выполнена и задокументирована
- [ ] Все цвета — пипеткой по нескольким точкам, с ролями и confidence
- [ ] Типографика — через ratio, снэпнута к type scale, weight из стандартных
- [ ] Spacing/радиусы снэпнуты к шкале, ни одного сырого значения
- [ ] Ни одного `high` confidence без пипетки/прямого замера
- [ ] `extracted` и `proposed` значения разделены
- [ ] Ограничения vision-only описаны, статус в study — `vision-only`
- [ ] Иконки: вес выбран (или `outline` low-confidence при неразличимости), SVG — из Reicon
- [ ] Моушен помечен как уровень C (изобретение на фазе 5), внесён в «Ограничения»
- [ ] Шрифты: кандидаты названы с confidence, лицензии проверены (`font-license-check`)

## Языковое покрытие шрифтов

То же правило, что в extraction-css.md: для каждого опознанного/предположенного
шрифта проверять лицензию + глифовое покрытие под язык контента + доступность в
Figma. Для vision-пути опознание шрифта и так probabilistic — аналог с кириллицей
подбирается по характеру (пропорции, контраст, x-height) с confidence-пометкой.
