# Путь Pencil: библиотека и макеты в .pen без Figma MCP

Этот док — для оператора без доступа к Figma MCP, работающего в
[Pencil](https://www.pencil.dev) (бесплатен в early access; ИИ-функции работают
через подписку Claude). Он заменяет фазы 4–6 основного пути Pencil-эквивалентом.
Все правила контракта действуют без ослаблений; артефакты проекта идентичны.
Итог — .pen-файл с библиотекой и макетами: в отличие от HTML-пути это
полноценная дизайн-канва (оператор/дизайнер может открыть и править), но для
клиента, ожидающего Figma, проекция выполняется отдельно оператором с доступом.

Обкатано на opora-pencil (2026-07-06, Pencil 1.1.68). Гайдлайны Pencil
(`get_guidelines`) агент читает ОБЯЗАТЕЛЬНО перед сборкой — они играют роль
скилла figma-use. Где гайдлайны Pencil противоречат контракту — контракт главнее.

## Фазы 0–3 — без изменений

Как в основном пути (`docs/workflow.md`). `tokens-before-pixels` действует:
до утверждённого tokens.json в .pen ничего не собирается.

**Specimen гейта 1** на этом пути — фрейм «00 Specimen» в .pen: палитра-свотчи,
шкала типографики кириллицей (языком контента), кнопки/бейджи, образец тёмной
секции; предъявляется скриншотом `get_screenshot`. Ловит отсутствие глифов,
курсивов и инверсию тем до пикселей — как Figma-specimen.

## Подключение (диагностика — читать ДО работы)

1. **Редактор должен быть запущен.** MCP подключается к работающему приложению.
2. **Транспорт привязан к варианту приложения** (`-app desktop` /
   `visual_studio_code` / …). Ошибка `failed to connect … visual_studio_code`
   при открытом standalone-приложении = сервер смотрит не туда; нужен сервер
   с `-app desktop`.
3. **Бинарник сервера должен быть свежим.** Копия в `~/.pencil/mcp/*/out/`
   может отставать от приложения и **рендерить пустые кадры** (однотонный фон
   при живой геометрии). Актуальный бинарник — внутри приложения:
   `Pencil.app/Contents/Resources/app.asar.unpacked/out/` (macOS). Тест:
   вставить прямоугольник с сырым hex и снять скриншот.
4. **Наборы инструментов различаются по сборкам/вариантам.** В desktop-варианте
   не реализованы `open_document` и `search_all_unique_properties` («No handler
   found») — файл открывает человек, аудит см. ниже. Свежие серверы имеют
   `export_html`; `SetVariables`/`FindEmptySpace` живут внутри `batch_design`.
5. **Лимит батча**: stdio-сервер обрезает строку ~4КБ — дробить `batch_design`
   на куски ≤3КБ JS.
6. **.pen — открытый JSON** в папке проекта (git-версионируется). Руками и
   Edit/Write его НЕ редактировать — только инструменты Pencil; читать для
   аудита можно. Приложение сохраняет файл по Cmd+S (не на каждое действие!):
   перед git-коммитом просить оператора сохранить; живое состояние доступно
   в `~/.pencil/backup/<hash>`.

## Фаза 4-pen: variables и компоненты

### Variables = коллекции Figma

`SetVariables` внутри `batch_design`, имена 1:1 с ключами tokens.json
(как в Figma и tokens.css): `palette-*`, `color-<роль>`, `font-heading/-body`,
`text-<ступень>-size/-line/-ls`, `space-*`, `radius-*`. Генерировать из
tokens.json скриптом, не руками (`scripts/tokens-to-pen-vars.mjs` — образец
вызова SetVariables).

Режимы коллекций Figma = **оси тем** Pencil (сильнейшая сторона пути):

- ось `mode: light|dark` на ролях `color-*` — тёмная секция получает
  `theme:{mode:"dark"}` на корне и инвертирует всё поддерево;
- ось `viewport: desktop|mobile` на числах типографики — мобильная страница
  с `theme:{viewport:"mobile"}` переключает всю шкалу одной осью.
  letterSpacing в Pencil в px: при генерации пересчитывать `em × size` по
  режимам. lineHeight — множитель, как в tokens.json.

Текст-стилей в Pencil нет: ступень = связка `$text-<step>-*` переменных,
вес и семейство задаются в компоненте. Эффект-стилей нет: тень = `effect.shadow`
с цветом-переменной; геометрия тени числами — поимённое исключение в worklog.

### Компоненты = reusable + ref

- Мастер: `reusable: true`. Инстанс: `{type:"ref", ref:<id>}` c override'ами
  через `descendants` (пути `instId/childId` для вложенных инстансов; подмена
  узла — override с `type`, так делается «вариант» вроде outline-бейджа
  внутри ячейки расписания).
- **Вариант-сетов НЕТ.** Конвенция имён: `Badge/Accent`, `Badge/Outline`,
  `Section/Hero (desktop)` / `(mobile)`. Состояния hover/focus непредставимы —
  правило hover остаётся текстовой спецификацией (образец-фрейм на странице
  компонентов + worklog).
- **Мастера держать внутри контейнер-фрейма** («01 Components», «02 Sections»),
  НЕ в корне документа: ref на корневой reusable-фрейм не рендерится (баг
  обкатки). После ресайза контейнеров проверять корень: соседние ноды
  геометрически «всасываются» внутрь.
- Wrap и min/max ширин нет: гриды — ручные ряды; мобильная композиция —
  отдельный компонент, ширины карточек — override'ами инстансов.
- Rich-text нет: курсивный акцент заголовка — ряд из текст-нод
  (обычная + `fontStyle:"italic"`); gap ряда = ширина пробела (исключение
  аудита). text-transform нет: капс лейблов пишется в контент (фиксируется
  в worklog, регистр источника хранит content-doc).
- Плейсхолдеры ассетов — заливка ролью + подпись слота; `Generate` (ai/stock)
  в v1 запрещён (`placeholders-for-assets`).
- `placeholder: true` на корневом фрейме на время сборки (норма Pencil) —
  снимать сразу по завершении фрейма.

### Страницы (фаза 5-pen)

Фреймы `home/desktop-1440`, `home/mobile-390` в корне документа: вертикальный
layout, дети — ТОЛЬКО инстансы секционных компонентов (`instances-only`).
Мобильная страница и мобильные мастера — `theme:{viewport:"mobile"}`.

### Иконки и моушен

- **Иконки:** вектор из Reicon по `docs/icons.md` (`fetch-icons`), в слот `icon`
  компонента; цвет — ролью-переменной (`icon-color-from-roles`), один вес на проект.
  Ручная отрисовка и другие коллекции запрещены (`icons-from-collection`).
- **Моушен:** в .pen не анимируется (движка нет). Поставка та же, что везде —
  `project/motion-spec.md` (фаза 5, `motion-spec-required`). Как и hover, моушен здесь —
  текстовая спецификация; дополнительно на анимируемый фрейм кладётся строка-аннотация
  (имя паттерна из `library/motion/`), чтобы разметка не расходилась со спекой.

## Фаза 6-pen: верификация

Те же три слоя `docs/verification.md`, средства:

1. **Аудит привязок** — `search_all_unique_properties`, если доступен; в
   desktop-варианте — скриптом по JSON документа (fill/stroke/effect-цвета,
   fontFamily/fontSize/lineHeight/letterSpacing, cornerRadius, gap/padding:
   всё, что не `$…` и не в поимённых исключениях worklog → ERROR).
   Плюс полнота секций и тексты против content-doc по тому же JSON.
2. **Геометрия** — `snapshot_layout`: машинно ловит переполнения и схлопнутые
   ноды (`problems: clipped/collapsed`) — сильнее скриншотов, гонять до них.
3. **Скриншот-сверка** — `get_screenshot` секций против эталонов
   `reference-shots/` (критерии — композиция/иерархия/плотность). Между
   вызовами паузы 3–5с и ретраи: частые вызовы возвращают обзор холста.
4. **Отчёт** — `project/verification-report.md`, пометка `режим: pencil`.

## Deliverable и передача

- **.pen-файл в `project/`** — первоисточник, версионируется git'ом
  (перед коммитом — Cmd+S у оператора).
- **PNG**: `get_screenshot` любых узлов; `export_nodes` — посекционно
  (на нодах размером со страницу падает/виснет).
- **export_html** страницы — рабочее кликабельное превью для клиента.
- Клиенту, ожидающему Figma: проекция фаз 4–5 оператором с Figma MCP из
  tokens.json (источник variables) + .pen как композиционного эталона —
  зеркально «Передаче» из `docs/fallback-html.md` (автоимпорт по умолчанию
  запрещён).

## Правила контракта в терминах Pencil

| Правило | В .pen означает |
| --- | --- |
| `no-detached-values` | только `$…` в цветах/шрифтах/кеглях/радиусах/отступах; исключения поимённо (геометрия тени, «пробельные» гэпы составных заголовков, текст-лого) |
| `instances-only` | страницы — только ref-инстансы; новый паттерн → мастер в контейнер компонентов (+ worklog), потом инстанс |
| `tokens-before-pixels` | SetVariables из tokens.json до любых фреймов; специмен-фрейм — единственное исключение (и обязанность) |
| `reference-source-of-truth` | стиль-каталог Pencil (`get_guidelines category:style`) НЕ использовать — система только из tokens.json |
| `worklog-required` | как везде + фиксировать инфраструктурные обходы подключения |
