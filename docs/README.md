# Правила фаз

Правила и форматы, которые агент читает по ходу прогона. Маршрут — `workflow.md`;
дисциплина и гейты — корневой `DESIGN-CONTRACT.md`. Один файл = одно правило фазы
или один формат; без дублирования между файлами.

| Файл | Что это |
| --- | --- |
| workflow.md | маршрутизация по фазам — точка входа |
| extraction-css.md | извлечение значений: CSS-путь (живой сайт) |
| extraction-vision.md | извлечение значений: vision-путь (скриншоты и картинки) |
| tokens-format.md | формат tokens.json |
| content-doc-format.md | единый формат контента и структуры |
| figma-library-rules.md | правила фазы 4: библиотека в Figma |
| assembly-rules.md | правила фазы 5: сборка макетов |
| verification.md | правила фазы 6: верификация |
| anti-patterns.md | каталог анти-паттернов AI-дизайна |
| icons.md | иконки: pixel-perfect из коллекции Reicon |
| motion.md | моушен: анимации как поставка |
| pencil-path.md | альтернативный путь: библиотека и макеты в .pen без Figma MCP |
| fallback-html.md | запасной путь: HTML-прототип без Figma MCP |
