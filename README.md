# design-kit

Переносимый рабочий комплект для генерации дизайн-систем и Figma-макетов сайтов на
основе референсов, с контрактной дисциплиной по образцу Toolcraft: reference study до
пикселей, дизайн-система как данные, гейты утверждения человеком, машинный аудит,
накопительная библиотека паттернов.

Спецификация: `thoughts/shared/specs/2026-07-05-figma-design-kit.md`
(в репо «toolcraft playground»).

## Состав

- `DESIGN-CONTRACT.md` — контракт с rule ID. Точка входа для агента.
- `docs/` — правила по фазам: workflow (маршрутизация), извлечение (CSS/vision),
  формат токенов, контент-док, библиотека Figma, сборка макетов, верификация, fallback.
- `templates/` — шаблоны артефактов проекта (study, inventory, design-system,
  content-doc, worklog, пример tokens.json).
- `library/` — накопительная библиотека паттернов (растёт между проектами, источник
  правды — здесь; Figma team library — генерируемая проекция).
- `scripts/validate-tokens.mjs` — валидатор tokens.json (шкалы, роли, WCAG-контрасты).
- `project/` — рабочая зона конкретного проекта (в шаблоне пустая).

## Как начать проект

1. Скопируй комплект в папку проекта (кроме `library/` — она читается из этого репо).
2. В Claude Code вызови скилл `design-kit` (или скажи «дизайн по референсу»).
3. Дальше агент ведёт по фазам и останавливается на гейтах утверждения.

## Требования

- Основной путь: Claude Code + Figma MCP (авторизованный) + доступ редактора в Figma.
- Запасной путь без Figma MCP: `docs/fallback-html.md`.
- Для CSS-пути извлечения: управляемый браузер (chrome-devtools MCP или claude-in-chrome).
