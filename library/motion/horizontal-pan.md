# horizontal-pan

| Поле | Значение |
| --- | --- |
| id | horizontal-pan |
| Тип | pin-scrub |
| Мотивация по умолчанию | storytelling (линейная лента, которую ведут скроллом) |
| Происхождение | seed (посевной, до первого проекта) |

## Что это

Вертикальный скролл пинит секцию и превращается в горизонтальное движение ленты
(галерея, таймлайн, набор карточек). Коммуницирует: контент — единая
последовательность, которую пролистывают слева направо.

## Классификация (уровень B)

Признаки в референсе: секция пинится (`position: fixed`/pin) на время прокрутки,
внутренний трек сдвигается по `transform: translateX(...)` синхронно со скроллом
(scrub), высота секции для скролла заметно больше вьюпорта.

## Канонический скелет (GSAP, HTML-путь)

Длина вертикального скролла = ширина трека за вычетом вьюпорта.

```js
const track = wrapper.querySelector(".track");
const distance = track.scrollWidth - wrapper.clientWidth;
gsap.to(track, {
  x: -distance,
  ease: "none",
  scrollTrigger: {
    trigger: wrapper,
    start: "top top",
    end: `+=${distance}`,
    pin: true,
    scrub: 1,
  },
});
```

`ease: "none"` — движение линейно привязано к скроллу; кривизну даёт `scrub`.

## Типовые ошибки

- `end` не равен дистанции трека — лента недоезжает или пустой пин в конце.
- Скролл-слушатель + ручной `requestAnimationFrame` вместо ScrollTrigger.
- Нет `pin` — секция уезжает вверх, горизонтального эффекта нет.
- Тяжёлый контент трека без `will-change`/оптимизации — рывки на слабых устройствах.

## Reduced motion

Схлопывается в горизонтально прокручиваемую ленту (`overflow-x: auto`) без pin и
скролл-хайджека — пользователь листает сам.

## Когда применять / когда НЕ применять

Применять: галерея работ, таймлайн, лента шагов — где линейный порядок и обзор «одно
за другим» важнее, чем немедленный доступ к каждому элементу.

НЕ применять: мобильные вьюпорты (скролл-хайджек ломает нативный скролл — на мобиле
деградировать в `overflow-x: auto`); контент, к которому нужен произвольный доступ;
больше одного pin-паттерна на странице.
