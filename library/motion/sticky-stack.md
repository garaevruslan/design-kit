# sticky-stack

| Поле | Значение |
| --- | --- |
| id | sticky-stack |
| Тип | pin-scrub |
| Мотивация по умолчанию | storytelling (последовательное раскрытие набора карточек) |
| Происхождение | seed (посевной, до первого проекта) |

## Что это

Набор карточек скроллится так, что каждая прилипает к верху вьюпорта, а следующая
наезжает поверх, слегка масштабируя и притемняя предыдущую. Коммуницирует: элементы —
части одной стопки, читаются по порядку, один за другим.

## Классификация (уровень B)

Признаки в референсе: карточки/панели с `position: sticky` (или pin через ScrollTrigger),
при скролле у нижележащей карточки уменьшается `scale` и `opacity` синхронно со
скроллом (scrub), порядок появления сверху вниз.

## Канонический скелет (GSAP, HTML-путь)

Каждую карточку масштабирует СЛЕДУЮЩАЯ; `start: "top top"` пинит карточку у верха.

```js
cards.forEach((card, i) => {
  const next = cards[i + 1];
  if (!next) return;
  gsap.to(card, {
    scale: 0.92,
    opacity: 0.55,
    scrollTrigger: {
      trigger: next,
      start: "top bottom",
      end: "top top",
      scrub: true,
    },
  });
});
```

Пин каждой карточки — отдельным ScrollTrigger с `pin: true`, `start: "top top"`.
Значения `scale`/`opacity` — из группы motion токенов проекта, не хардкодом.

## Типовые ошибки

- Скролл-слушатель вместо ScrollTrigger — перерисовка на каждый фрейм, дёрганье.
- Масштабирование самой карточки её же триггером (визуальный джиттер) — масштабирует
  ВСЕГДА следующая карточка.
- Нет `scrub` — анимация «прыгает» рывком вместо привязки к скроллу.

## Reduced motion

Схлопывается в обычный вертикальный стек карточек без pin, scale и opacity —
просто список секций.

## Когда применять / когда НЕ применять

Применять: 3–6 равнозначных блоков-этапов, которые нужно прочитать по порядку
(шаги процесса, принципы, кейсы).

НЕ применять: карточек > ~6 (стопка утомляет); контент, где важен обзорный взгляд
на все элементы сразу (тогда bento/grid); больше одного pin-паттерна на странице.
