## Анатомия (слоты)

- **label** (обязательный) — мини-лейбл секции.
- **heading** (обязательный) — серифный заголовок h2-класса; в варианте
  «персона» — лид + имя тем же шагом.
- **text** (обязательный) — 2–5 строк поддерживающего текста.
- **cta** (опциональный) — кнопка/ссылка.
- **media** (обязательный) — крупное фото/видео со скруглением; в варианте
  «персона» — вертикальный портрет (~7:8).

## Композиция desktop

Две колонки ~5.5/12 + 5.5/12 с очень крупным gap (~1/12), вертикальное
выравнивание по центру. Текстовый стек слева (label → heading → text → cta),
media справа во всю колонку. Отличие от hero-split: это секция середины
страницы — без social-proof и вторичных CTA, доминанта спокойнее.

## Композиция mobile

Стек: label → heading → text → cta → media. Gap схлопывается до обычного ритма.

## Когда применять

- «О студии/компании», «об основателе», рассказ об одной услуге — один смысл,
  один визуал.

## Когда НЕ применять

- Первый экран лендинга — используйте hero-split (там есть CTA-ряд и social-proof).
- Несколько равных фич — нужен грид, а не серия сплитов подряд (максимум 2 на страницу).
