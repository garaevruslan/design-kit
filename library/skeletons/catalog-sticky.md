## Анатомия (слоты)

- **page-title** (обязательный) — заголовок каталога («Все занятия», «Все события»).
- **intro** (обязательный) — вводный текст 2–4 строки под заголовком.
- **filter** (опциональный) — фильтр категорий (см. компонент filter-tabs-underline).
- **list** (обязательный) — грид или вертикальный список карточек каталога.

## Композиция desktop

Грид ~3.5/12 + 7.5/12 с крупным gap (доля ~1/12 между колонками). Левая колонка —
sticky (прилипает с отступом от верха при скролле): page-title → intro → filter.
Правая — list: вертикальный список карточек (события) или грид 2 колонки
(занятия) / 3 колонки (товары), gap плотный по вертикали у грида.

## Композиция mobile

Один стек: page-title → intro → filter → list (1–2 колонки). Sticky отключается.

## Когда применять

- Каталожные страницы с одним типом сущности: занятия, события, товары, статьи.
- Когда нужен постоянно видимый контекст (что за список и как он отфильтрован).

## Когда НЕ применять

- Короткий список (≤3 позиции) — сайдбар избыточен, хватит секции с гридом.
- Сложная многофасетная фильтрация — sticky-колонка не вместит фасеты.
