## Анатомия (слоты)

- **credo** (обязательный) — текст-кредо 3–5 строк, центрирован.
- **divider** (опциональный) — тонкая вертикальная линия.
- **values** (опциональный) — ряд из 3 пунктов: иконка + uppercase-подпись.

## Композиция desktop

Всё по центральной оси: credo (ширина ~720, по центру) → divider → ряд values.
Пункты values РАВНОЙ фиксированной ширины (~220), контент центрирован — иначе
визуальный перекос (урок прогона).

## Композиция mobile

Credo сужается (~340). Values складываются в вертикальный стек по центру.

## Когда применять

- Отстройка идеологией: секция-«выдох» между hero и продуктовыми секциями.

## Когда НЕ применять

- Текста больше 5 строк — это уже about-секция, не манифест.
