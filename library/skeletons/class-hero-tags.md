## Анатомия (слоты)

- **media-bg** (обязательный) — полноширинный фон: видео/фото с тонирующей подложкой.
- **tags** (обязательный) — ряд тег-чипов свойств сущности (уровень, длительность).
- **heading** (обязательный) — название сущности, самый крупный шаг.
- **description** (обязательный) — 2–3 строки, ограниченная ширина (~1/3 контейнера).
- **author-tile** (опциональный) — карточка ведущего/автора (см. компонент author-tile).

## Композиция desktop

Один экран или чуть меньше; крупный верхний отступ (под плавающую навигацию).
Текстовый стек слева: tags → heading → description. author-tile — нижний правый
угол (прижат к низу секции).

## Композиция mobile

Стек: tags → heading → description → author-tile (на всю ширину). Порядок сохраняется.

## Когда применять

- Детальная страница занятия/курса/услуги, у которой есть 2–4 ключевых свойства,
  выносимых в теги, и персона-ведущий.

## Когда НЕ применять

- У сущности нет свойств для тегов и персоны — хватит простого текстового hero.
- Главная страница — там hero должен продавать оффер, а не описывать сущность.
