## Анатомия (слоты)

- **label** (опциональный) — uppercase-надзаголовок секции.
- **heading** (опциональный) — заголовок, допускается курсивный акцент.
- **intro** (опциональный) — вводный абзац.
- **steps ×N** (обязательный) — карты этапов (см. компонент card-step-tall):
  index → title → description. Обычно N = 4–6.
- **closing** (опциональный) — финальная строка/цитата под лестницей.

## Композиция desktop

Ряд из N карт этапов, каждая последующая смещена **вверх** относительно предыдущей —
«восходящая лестница». Смещение по вертикали — декоративное **абсолютное**
позиционирование карт (осознанное исключение из autolayout: autolayout не даёт
по-элементного вертикального оффсета — фиксируется в worklog проекта поимённо).
Карты — фиксированной высоты ради ровных ступеней. Секция обычно тёмная (карты
card-step-tall на тёмном фоне).

## Композиция mobile

Лестница разворачивается в **вертикальный стек** карт на всю ширину (без абсолютного
оффсета — обычный autolayout VERTICAL). Порядок этапов сверху вниз. Карты — `HUG`
по высоте (описание не обрезается). label/heading/intro — над стеком.

## Когда применять

- Последовательность из 4–6 именованных этапов пути/процесса, где важно ощущение
  восхождения/прогресса.
- Когда каждый этап несёт номер + название + короткое описание.

## Когда НЕ применять

- Этапов 1–3 (слишком мало для лестницы — сплит или тройка карт).
- Когда порядок не важен (тогда обычная сетка card-*).
- Когда нет ресурса на ручное декоративное позиционирование desktop-оффсета —
  выродится в обычный ряд, лестница не читается.
