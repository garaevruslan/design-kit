## Анатомия (слоты)

- **label** (обязательный) — uppercase-лейбл секции.
- **heading** (обязательный) — заголовок, допускается курсивный акцент.
- **support** (опциональный) — поддерживающий текст справа от заголовка.
- **link** (опциональный) — текстовая ссылка-underline при support.
- **cards ×3** (обязательный) — карточки: media + title + description.

## Композиция desktop

Шапка: label+heading слева, support+link справа (SPACE_BETWEEN).
Грид 3 равных карточки, gap 16, каждая FILL по ширине.

## Композиция mobile

Шапка в один столбец (label → heading → support → link).
Карточки в вертикальный стек, каждая на всю ширину.

## Когда применять

- Три равнозначных направления/фичи/категории с медиа.

## Когда НЕ применять

- Больше 4 пунктов — сетка, не тройка; меньше 3 — сплит.
