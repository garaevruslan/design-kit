## Анатомия (слоты)

- **nav** (обязательный) — плавающая навбар-пилюля по центру сверху.
- **heading** (обязательный) — крупный дисплейный заголовок, допускается курсивный акцент.
- **subheading** (обязательный) — 1–3 строки поддержки.
- **cta-primary** (обязательный) — кнопка действия.
- **announce-card** (опциональный) — маленькая карточка-анонс с бейджем.
- **media-bg** (обязательный) — полноэкранный фото/видео-фон.

## Композиция desktop

Секция на высоту экрана (~780). Медиа — фон целиком. Nav — пилюля по центру
сверху с отступом. Текстовый стек (heading → subheading → CTA) — нижний левый
угол. Announce-card — нижний правый угол. Вертикаль: SPACE_BETWEEN.

## Композиция mobile

То же расположение, announce-card скрывается. Подзаголовок сужается (~340),
CTA остаётся под текстом. Высота ~700.

## Когда применять

- Лендинг с атмосферным медиа и одним оффером; первый экран «настроение + действие».

## Когда НЕ применять

- Нет достойного полноэкранного медиа — плейсхолдер на весь экран ослабляет вход.
- Несколько равнозначных офферов на первом экране.
