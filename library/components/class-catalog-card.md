# class-catalog-card

| Поле | Значение |
| --- | --- |
| id | class-catalog-card |
| Назначение | Карточка занятия в каталоге: квадратное фото, ряд тегов, название, описание — без подложки |
| Происхождение | yoga-school-demo, дообогащение (референс hollow-template.webflow.io: /classes), 2026-07-06 |

## Props / варианты

нет (уровень выражается инстансом тега, не вариантом карточки)

## Состояния

нет в v1 (карточка-ссылка; hover — за пределами извлечённого)

## Слоты контента

- media — квадратное фото 1:1, скругление md
- tags — ряд инстансов tag-pastel-level (уровень + длительность + ведущий)
- title — название (шаг h5-класса, sans)
- text — 1–3 строки (body, text-muted)

## Роли токенов (только роли, не значения)

surface-alt (плейсхолдер фото), text, text-muted, radius.md,
spacing (gap 20 медиа↔контент, 12 в контенте, 8 между тегами)

## Мобильное поведение

FILL по ширине колонки; в референсе грид каталога остаётся 2-колоночным
даже на мобиле — карточка выдерживает узкую колонку (теги переносятся).
