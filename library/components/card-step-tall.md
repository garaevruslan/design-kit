# card-step-tall

| Поле | Значение |
| --- | --- |
| id | card-step-tall |
| Назначение | Высокая тёмная карта этапа пути: индекс сверху, крупный serif-заголовок и описание снизу (номер и текст разнесены по вертикали) |
| Происхождение | dk-sabi (SABI Центр), 2026-07-13 |

## Props / варианты

нет (один вариант; тёмная карта по умолчанию — используется на тёмной секции-лестнице).

## Состояния

нет в v1 (неинтерактивная карта-этап; hover — за пределами извлечённого).

## Слоты контента

- index — номер этапа (01, 02, …), короткий лейбл сверху; акцентная роль.
- title — название этапа, крупный серифный шаг (h3), 1–2 строки.
- description — 2–4 строки (body); на мобиле высота карты HUG по описанию.

Вертикальная раскладка `SPACE_BETWEEN`: index прижат к верху, title+description — к низу
(на десктопе, где карта фиксированной высоты ради ровных ступеней). На мобиле —
`HUG` по высоте, `MIN`-выравнивание, положительный gap вместо space-between.

## Роли токенов

color.surface-dark (фон карты), color.text-on-dark (заголовок и описание на тёмном),
color.accent или color.text-on-dark (индекс), color.border / хайрлайн через
text-on-dark низкой прозрачности (тонкая рамка на тёмном), radius.md.
Только роли — значения приходят из tokens.json проекта.

## Мобильное поведение

Autolayout-поведение: карта `layoutSizingHorizontal=FILL`, высота — `HUG`
(`layoutSizingVertical=HUG`, `primaryAxisAlignItems=MIN`, положительный itemSpacing
вместо `SPACE_BETWEEN`). Фиксированная высота уместна ТОЛЬКО на десктопе, где карты
образуют ровные ступени лестницы (см. skeleton staircase-steps); на мобиле хардкод
высоты обрезает длинное описание.
