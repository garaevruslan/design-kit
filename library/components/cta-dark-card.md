# cta-dark-card

| Поле | Значение |
| --- | --- |
| id | cta-dark-card |
| Назначение | Тёмная карточка способа действия: заголовок, пояснение, малая кнопка; работает инверсией (dark-режим) на светлой странице |
| Происхождение | yoga-school-demo, дообогащение (референс hollow-template.webflow.io: /classes/yin-yoga, /timetable), 2026-07-06 |

## Props / варианты

нет (один вариант; карточка целиком живёт в dark-режиме семантической коллекции)

## Состояния

нет (интерактивна кнопка внутри, не карточка)

## Слоты контента

- title — заголовок способа (body-bold)
- text — пояснение 2–4 строки (body, text-muted)
- button — инстанс кнопки size=sm (или контакт-ссылка)

## Роли токенов (только роли, не значения)

bg (в dark-режиме — тёмный полюс), text, text-muted, radius.md,
spacing (паддинг 24, gap 12); кнопка — свои роли (fill-subtle/border/text)

## Мобильное поведение

FILL по ширине, квадратная пропорция отпускается; кнопка остаётся прижатой к низу.
