| id | feature-card-square |
| Назначение | Квадратная карточка-преимущество: иконка вверху, заголовок и текст прижаты к низу |
| Происхождение | yoga-school-demo, дообогащение (референс hollow-template.webflow.io: /classes/yin-yoga), 2026-07-06 |

## Props / варианты

нет (один вариант)

## Состояния

нет (неинтерактивная карточка)

## Слоты контента

- icon — линейная иконка 48
- title — заголовок (body-bold)
- text — 1–3 строки (body, text-muted)

## Роли токенов (только роли, не значения)

surface, text, text-muted, radius.md, spacing (паддинг 24, gap 12 в текст-стеке)

## Мобильное поведение

FILL по ширине, квадратная пропорция отпускается (hug по контенту);
воздух между иконкой и текстом остаётся за счёт space-between.
