# event-card

| Поле | Значение |
| --- | --- |
| id | event-card |
| Назначение | Крупная карточка события: широкоформатное фото + дата/название/локация и описание в две колонки |
| Происхождение | yoga-school-demo, дообогащение (референс hollow-template.webflow.io: /events), 2026-07-06 |

## Props / варианты

нет (один вариант; прошедшие события отличаются контентом, не композицией)

## Состояния

нет в v1 (карточка-ссылка; hover — за пределами извлечённого)

## Слоты контента

- media — фото ~16:9 сверху во всю ширину, углы скрыты подложкой карточки
- date — uppercase-мини-лейбл (caption-sm)
- title — название серифным шагом h4
- location — uppercase-лейбл (caption, text-muted)
- description — 2–4 строки (body)

## Роли токенов (только роли, не значения)

surface, surface-alt (плейсхолдер фото), text, text-muted, radius.md,
spacing (контент-паддинги 32/24, gap 16)

## Мобильное поведение

Контентный ряд «мета | описание» — wrap с минимальной шириной колонок:
на узких экранах складывается в одну колонку (мета → описание).
