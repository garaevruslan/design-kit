# author-tile

| Поле | Значение |
| --- | --- |
| id | author-tile |
| Назначение | Компактная карточка персоны: фото + имя + короткое био; для hero детальных страниц и подписей к контенту |
| Происхождение | yoga-school-demo, дообогащение (референс hollow-template.webflow.io: /classes/yin-yoga), 2026-07-06 |

## Props / варианты

нет (один вариант)

## Состояния

нет (неинтерактивная карточка)

## Слоты контента

- media — квадратное фото ~96, скругление md
- name — имя (body-bold)
- bio — 1–3 строки (body, text-muted)

## Роли токенов (только роли, не значения)

surface, surface-alt (плейсхолдер фото), text, text-muted, radius.md,
spacing (паддинг 16, gap 24 фото↔текст, 8 в текст-стеке)

## Мобильное поведение

FILL по ширине; био переносится, фото фиксированное.
