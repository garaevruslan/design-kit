# inputs — yoga-school-demo

## Референсы

- **Основной:** https://hollow-template.webflow.io/ (живой сайт, Webflow-шаблон) —
  путь извлечения: css-path.

## Бриф

Вымышленный продукт для тестового прогона комплекта design-kit v1.

- **Продукт:** онлайн/офлайн школа йоги (рабочее имя согласуем в фазе 3).
- **Тип:** лендинг, 1 страница.
- **Обязательные смысловые блоки (от заказчика):** идеология школы, направления
  (стили йоги), тарифы, преподаватели, расписание, FAQ.
- **Контент:** готового контента нет — генерируется в фазе 3 из этого брифа
  (сценарий Б по docs/content-doc-format.md).
- **Аудитория:** взрослые новички и продолжающие, город-миллионник.
- **Целевое действие:** запись на пробное занятие.

## Масштаб и брейкпоинты

- 1 страница (лендинг), desktop 1440 + mobile 390.
- Гейты 2 и 3 НЕ объединяем с гейтом 1: это тестовый прогон, проверяем все гейты
  по отдельности (решение оператора, фиксируется в worklog).
