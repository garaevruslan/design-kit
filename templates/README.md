# Шаблоны артефактов проекта

Заготовки, которые агент копирует в `project/` нового прогона и заполняет данными
из референса. Плейсхолдеры (`{{project-name}}`, `<название проекта>`) — заменяются;
структура разделов — не меняется. Скаффолдер: `scripts/create-project.mjs`.

| Файл | Что это |
| --- | --- |
| reference-inventory.md | опись референса: страницы, экраны, что извлекать |
| reference-study.md | изучение референса до пикселей (фаза 1) |
| design-system.md | дизайн-система как данные (фаза 2) |
| tokens.example.json | пример структуры tokens.json |
| content-doc.md | контент и структура сайта (фаза 3) |
| motion-spec.md | спецификация моушена |
| worklog.md | worklog прогона — decision trail |
