инспектированных страниц/скриншотов референса. Секция, которая не переносится
в проект, получает статус `intentionally-skipped` с причиной. Молча пропускать
секции запрещено: отсутствие секции в инвентаре = несданная фаза 1.

Статусы переноса:

- `planned` — переносим, компонент ещё не спроектирован;
- `mapped` — переносим, целевой компонент библиотеки назначен;
- `intentionally-skipped` — не переносим, причина обязательна.
